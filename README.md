# 📩 Spam Email Detection System

A machine learning-based web application that classifies emails as Spam or Not Spam using Natural Language Processing techniques.

---

## 🌐 Features

- 📥 Input any email/message
- 🤖 Detects Spam or Not Spam
- 📊 Shows confidence score
- ⚡ Real-time prediction using trained ML model

---

## 🛠️ Tech Stack

- Python
- Scikit-learn
- Pandas
- Streamlit
- NLP(basic) (TF-IDF Vectorization)

---

## 🧠 How It Works

- Text data is preprocessed and converted into numerical form using TF-IDF
- A Multinomial Naive Bayes model is trained on the dataset
- The model predicts whether the input message is spam or not
